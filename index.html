Model, measurements, and playback limits

This is a purpose-built chemical-body model, not a living animal, a microbiome model, or proof of a theory of personal identity. A and B are two locally interacting catalytic populations. They convert a shared precursor Q into more active material; active material returns to Q. Slow diffusion of A/B and faster diffusion of Q allow a localized body to persist. There is no target silhouette, prewired ring, or repair force.

J = c (4 + s + 1.8m) QAB / (1 + AB)
∂t A = 0.16 ∇²A + J − A
∂t B = 0.16 ∇²B + J − B
∂t Q = 2.00 ∇²Q − 2J + A + B
∂t m = 0.02 ∇²m + ηs(A+B)/(1+A+B)(1−m) − 0.0002m

c = reaction coupling; s = local experimental pulse
m = slow local chemical trace, enabled in the memory test

Same solver. Build 11 preserves the build-10 engine byte for byte. The 64×64 periodic bath, nine-point diffusion stencil, initial seed, and fixed integration step 0.04 are unchanged. The shared baseline is grown with 20,000 actual simulation steps before the interventions. Assembly begins with the noisy seed itself. Initialization supplies a local chemical patch; this is not life emerging from an empty universe.

Observation time. Playback pace changes solver steps per wall-clock second, not the integration step. Short collapse and early repair are shown slowly; long relaxation stages are accelerated and labelled. “0.5×” is relative to each stage’s demonstration pace, not a constant conversion between seconds and model time. Every control advances through exactly the same number of solver steps as its experimental sample. Model time is shown and exported.

Inspection, not a new force. Checkpoints freeze the entire state until Continue. Small step advances a short, stage-dependent batch of actual solver steps. Off-screen and background-tab runs pause. Review shows recorded concentration states and holds the live computation; scrubbing is not reverse physics. Return to latest state before resuming. Reset and Replay deliberately reload the experimental starting state; recovery never does.

What is measured. Body area counts sites with A+B > 1, the same threshold as the drawn contour. Material sums A+B+Q. Puncture closure counts active sites inside the actual wound, not exact silhouette similarity. The original-material fraction follows three neutral tracer fields through reactions and transport. Values below 0.1% are a bound, not exact zero. Memory difference is the L1 difference from the same-pulse, no-trace control, divided by its active material. The difference image uses a fixed signed scale of ±1 concentration unit; values outside that scale saturate, and the normal Body view remains available.

Interpretation. Turnover changes labels through actual material exchange while assuming old and new matter are chemically identical. Injury converts active material into precursor without deleting its total. Memory retains a slowly fading local catalyst modification. The Holobiont test deliberately requires both partners in its local reaction law; isolated controls convert the missing partner to precursor with the same total material. A disappearing outline is loss of the measured high-density body, not loss of all matter. Long interruptions may leave too little catalyst for restoration to work. That quiet failure is retained.

The model is inspired by local bistability, mass conservation and unequal diffusion in Mori, Jilkine & Edelstein-Keshet (2008), but is not their published cell-polarization model. Source · Playback checks. Historical quotations are reflections, not evidence for the experiments.

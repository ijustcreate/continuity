What is real in this model—and what is not?

This is a purpose-built chemical-body model, not a living animal, a microbiome model, or proof of a theory of personal identity. Two catalytic populations, A and B, locally turn a shared dissolved precursor Q into more active material. Active material continually returns to the precursor. Slow diffusion of A/B and fast diffusion of Q allow a localized body to persist. The simulation uses no target silhouette, no prewired ring, no stored particle roles, and no “repair” force.

J = c (4 + s + 1.8m) QAB / (1 + AB)
∂t A = 0.16 ∇²A + J − A
∂t B = 0.16 ∇²B + J − B
∂t Q = 2.00 ∇²Q − 2J + A + B

c = reaction coupling; s = local experimental pulse
m = slow local chemical trace (enabled only in the memory test)
∂t m = 0.02 ∇²m + ηs(A+B)/(1+A+B)(1−m) − 0.0002m

Numerics. The same 64×64 periodic bath, eight-neighbour, nine-point diffusion and fixed integration step of 0.04 are used everywhere. A seeded, noisy chemical patch is necessary; this is not spontaneous life from an empty universe. The common baseline is grown by 20,000 actual simulation steps when the page opens, then copied as the starting condition for the interventions. Assembly replays the seed itself. No reference image enters the equations. Previews, contour lines and outcome measurements do not exert forces.

What the tests change. Turnover swaps dissolved precursor with an equal amount of chemically identical, differently labelled material. Three additional tracer fields follow that label through diffusion, decay and renewed synthesis; the body is not merely recoloured by a timer. Injury converts active material in a patch into dissolved precursor, preserving total material; it models chemical deactivation, not excised flesh. Memory deposits a dimensionless, slowly fading local catalyst trace and compares the result with the same pulse without trace formation. The Holobiont panel tests the explicitly designed mutual-catalysis assumption using A-only, B-only and paired controls. Its populations are chemical surrogates—not actual microorganisms.

Measurements. “Body area” counts grid sites with A+B > 1; the drawn contour uses exactly that threshold. “Material” sums A+B+Q over the bath. Hole closure counts restored active sites inside the actual injury region; it does not test an exact silhouette. “Original” is the labelled fraction of active material. Values below 0.1% are reported as a bound, never falsely as exact zero. Memory difference is the L1 concentration difference relative to the matched no-trace control. Model time—not wall-clock time—is exported. Playback rates differ between fast chemical collapse and slower spatial recovery so both can be inspected.

Controls and limits. Most panels run an unaltered matched control, shown as a thumbnail and a dashed trace. A disappeared outline means loss of the measured high-density body, not disappearance of every active molecule. Early restoration can succeed from residual chemistry; after stronger interruption it can fail. Replay/Reset explicitly restores the experimental starting state; recovery never does. Off-screen runs pause so you do not miss the intervention. These tuned examples are computational demonstrations under chosen assumptions, not general biological results.

The model is inspired by local bistability, mass conservation and unequal diffusion in Mori, Jilkine & Edelstein-Keshet (2008), but is not their published cell-polarization model. Inspect the code and verification tests. Historical quotations below the experiments are reflections, not evidence for their results.
